# AETERNISM Android
Upload this project to the root of your GitHub repository. GitHub Actions builds the APK automatically.

Included:
- AETERNISM app name and custom launcher icon
- Original xi_deck_with_images.html interface
- Automatic Android audio/video MediaStore scan
- Runtime media permissions
- Add scanned media directly to the player
- Rename, delete, and share actions for scanned media

Android may require system approval for modifying media files not created by this app.
